# Labs, Learnings & Demos 🧪

A hands-on collection of labs, experiments, troubleshooting exercises, demos, and technical notes created while learning and working with infrastructure, containers, Kubernetes, cloud, and related technologies.

The repository focuses on **practical learning** — building things, testing them, troubleshooting problems, and documenting what was learned.

## 🎯 What This Repository Contains

* Hands-on technical labs
* Working demonstrations
* Experiments and proof-of-concepts
* Troubleshooting exercises
* Configuration examples
* Scripts and commands
* Technical notes and lessons learned

## 🔬 Learning Approach

```text
Learn
  ↓
Build
  ↓
Test
  ↓
Break
  ↓
Troubleshoot
  ↓
Understand
  ↓
Document
```

The objective is not simply to collect commands or follow tutorials.

The focus is on understanding **how systems work, why they fail, how to troubleshoot them, and how to build them correctly.**
